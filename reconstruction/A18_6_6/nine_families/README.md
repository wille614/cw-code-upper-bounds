# SEM02a — 独立重建 A(18,6,6) 的九族约束

结论：指定九族 **16095 个块全部逐项相等**，共 **693971 个非零系数键**；公共变量表独立枚举为 **1、4、35、901**。详细数学证明、范围与独立性披露、实际运行时间见 `SEM02a_report.md`。

## 离线复现

需要 Python 3.10 或以上以及支持 C++17 的 g++。本次使用 Python 3.12.14、g++ 14.2.0。无需 pip 包或网络。

```sh
cd SEM02a_audit
python3 run_all.py
```

运行入口从三个原始附件开始，重算轨道，再按用户指定顺序重建和比较九族。最后应报告 `equal_blocks=16095`、`compared_nonzero_keys=693971`。若有任何差异，立即停止并留下差异报告。

`occupancy_matrix.py` 使用 `-mpopcnt` 编译选项，适用于本次 x86 环境。其他架构可去掉该选项或换成适当选项；程序使用的整数算法不变。

重跑会更新 `data/` 中的结果与计时，建议先复制目录再重跑。下载包中的 `data/first_run_summary.json` 是首轮记录；`data/reproduction_summary.json` 是在隔离空目录中用统一入口重新运行的记录。隔离复现花费33.547370秒，所有块与首轮系数完全一致。

## 独立性与证据边界

- 各重建模块只读系数剥离后的标签和独立生成的轨道表；模型 `entries` 仅由 `compare.py` 用于比较。
- 所有系数精确运算，Python 无界整数；C++ 固定代表计数的绝对值有已证明上界199147520。
- 生成方附录未用作证据或测试期望值。最初阅读时部分算例曾显示，因此不声称事前未见数值的盲审；完整披露在报告§2.2。
- D0、D2、最后23个leave块和有理对偶证书不属于本次范围。
- cardinality三族依赖附件援引的已知 `A(17,6,6)<=124`；124到186的推导已核对，124本身的外部证明没有重验。

## 文件

- 源程序在顶层，原始附件在 `upload/`。
- 完整重建和逐块比较文件为 `data/rebuilt_*.json`、`data/comparison_*.json`。
- `data/orbits.json` 是独立生成的941轨道，`data/extension_map.json` 是前40轨道的独立基数局部化映射。
- `data/cardinality_rooted_sources.json` 保存第八族的完整原始及归一化源矩阵。
- `data/occupancy_basis.tsv` 保存第七族在固定代表上的三个整数基系数。
- `MANIFEST.sha256` 列出包内文件哈希（不含清单自身）。

主报告是结论的最终版本；`*_notes.md` 与 `validity_review.md` 是各实现分支的推导材料，首轮计时和第二轮复现记录应按主报告区分。
