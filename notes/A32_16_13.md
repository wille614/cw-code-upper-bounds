# A(32,16,13) <= 26

The proof uses integer column weights, Gram matrices, orthogonal
projections, and explicit integer separation certificates. It does not
require a Hadamard completion theorem. Integer column-weight bounds
already occur in Best et al. [1, Theorem 17]. Orthogonal projection is
standard linear algebra; the separation principle is described in [2].
All finite parts below are checked by
`python verify.py 32 16 13` with two complete certificate sets.

## 1. A budget of five

Represent M codewords as 13-subsets c_a of a 32-set. Distinct words
intersect in at most 5 points. Put delta_ab=5−|c_a intersection c_b|,
and let r_j be the column weights. Then

    sum_j r_j = 13M,
    sum_j binom(r_j,2) = 5 binom(M,2) − sum_(a<b) delta_ab.

For any integers r,q,

    binom(r,2) = qr − q(q+1)/2 + (r−q)(r−q−1)/2,

and the last term is nonnegative. At M=28,q=11 this forces
sum_j binom(r_j,2)>=1892, whereas 5 binom(28,2)=1890. Thus M<=27;
every larger code would contain a 28-word subcode.

At M=27,q=10 the identity becomes

    sum_(a<b) delta_ab + sum_j (r_j−10)(r_j−11)/2 = 5.

The positive delta_ab form a loopless weighted graph of total edge
weight at most five and at most ten nonisolated vertices. All such graphs
are covered by partitioning the 2t endpoints of t labeled unit edges,
rejecting loops, and merging parallel edges. Each weighted graph has such
an expansion. Complete isomorphism tests identify equal graphs; the
numbers of classes for t=0,1,2,3,4,5 are 1,1,3,8,23,66, totaling 102.
Both checkers enumerate every endpoint partition and verify coverage
against the entire supplied graph list. The counts of loopless partitions
are 1,1,7,87,1657,43833. No classification is accepted solely by its hash.

## 2. The one-coordinate conditions

Replace each binary row by x=1−2c. The symbol matrix X satisfies

    XX^T = H = 32I−4D,        X 1 = 6·1,

where D is the defect adjacency matrix. Each weighted vertex degree is
at most five. Using 2|z_i z_j|<=z_i²+z_j² gives z^T H z>=12||z||²;
therefore H is positive definite. Define

    beta = 6H^(-1)1,       S = 32−36·1^T H^(-1)1.

Here S is the squared norm of the component of the all-one vector
orthogonal to the row space of X. S<0 is impossible. If S>0, the projector
onto that row space plus the all-one vector is

    P = X^T H^(-1)X + (1−X^T beta)(1−X^T beta)^T/S.

It satisfies 0<=P<=I. Thus every symbol column z has
z^T H^(-1)z + (1−beta^T z)²/S<=1. At S=0 the conditions instead are
beta^T z=1 and z^T H^(-1)z<=1.

Suppose the graph has v nonisolated rows and u=27−v isolated rows.
A column type is (b,a), where b is its binary restriction to the v rows
and a is the number of ones on the u isolated rows. The isolated part
contributes u/32 to the quadratic form and (3/16)(u−2a) to beta^T z.
The checks enumerate all 2^v(u+1) possibilities, test the rational
projection condition, and retain only types satisfying

    (a+|b|−10)(a+|b|−11)/2 <= 5−sum delta_ab.

Let N_(b,a) be the number of columns of a retained type. Necessarily N>=0,
and the following equations hold:

| Sum over column types | Right side |
|---|---|
| sum N | 32 |
| sum aN | 13u |
| sum binom(a,2)N | 5 binom(u,2) |
| sum b_i N, for each nonisolated i | 13 |
| sum ab_i N, for each nonisolated i | 5u |
| sum b_i b_j N, for each nonisolated pair i<j | 5−delta_ij |

These count coordinates, incidences, and row intersections. A rational
negative S excludes 72 graphs. Integer linear certificates for these
equations exclude 22 more. Exactly eight graphs remain, numbered
0,1,2,3,4,10,11,12 in the supplied data.

## 3. Two distinct coordinates

For types i=(b,a), j=(b',a'), let t be the number of isolated rows having
a one in both coordinates, so max(0,a+a'−u)<=t<=min(a,a'). Write
z_b=1−2b, let H_v be the nonisolated principal block, and put

    e_i = 1−beta_v^T z_b − (3/16)(u−2a),
    p_ij = z_b^T H_v^(-1) z_b' + (u−2a−2a'+4t)/32 + e_i e_j/S.

All eight graphs have S>0. If p_i,p_j are the corresponding diagonal
projector entries, the two-coordinate principal minor of I−P requires

    p_ij² <= (1−p_i)(1−p_j).

All type pairs and integer overlaps are tested exactly.

Let Z_(i,j,t) count the ordered pairs of distinct coordinates of these
types and overlap. For i!=j use one variable for the equal forward and
reverse counts. For i=j the variable already counts both directions;
do not introduce another factor of two. Its parity is immaterial to a
nonnegative real relaxation.

Fix a first coordinate of type i=(b,a). Put h=a'−t. The sum of each
feature of the second coordinate over the remaining 31 coordinates is:

| Feature | Required sum |
|---|---|
| 1 | 31 |
| t | 12a |
| h | 13(u−a) |
| binom(t,2) | 4 binom(a,2) |
| th | 5a(u−a) |
| binom(h,2) | 5 binom(u−a,2) |
| b'_k | 13−b_k |
| tb'_k | a(5−b_k) |
| hb'_k | 5(u−a) |
| b'_k b'_l | 5−delta_kl−b_k b_l |

For example each of the a isolated rows occupied in the fixed column
has twelve ones left, and each pair of them has four common ones left.
An isolated row from each of the two classes still has five common ones;
the last four equations subtract the fixed column in the same way.
Multiply each equation by N_i and sum over the first coordinates.
Together with the single-column equations this gives A(N,Z)=rhs,
with all variables nonnegative.

## 4. The integer certificates

Each certificate is an integer vector y with A^T y<=0 and rhs^T y>0.
Then any nonnegative solution would give
0<rhs^T y=(N,Z)^T A^T y<=0, a contradiction. There is no tolerance.
Every coefficient, including each right-hand side, is rebuilt from the
formulas above. The certificate files contain all vector components.

| Graph | Types | Pair variables | First set rhs^T y | Second set rhs^T y |
|---:|---:|---:|---:|---:|
| 0 | 3 | 11 | 380100 | 15900 |
| 1 | 11 | 88 | 10166280956550 | 101015500 |
| 2 | 36 | 775 | 17332892502687 | 172741660 |
| 3 | 8 | 56 | 17332892538832 | 172678000 |
| 4 | 16 | 198 | 17332892475776 | 172725640 |
| 10 | 13 | 114 | 24491570217444 | 244335340 |
| 11 | 25 | 437 | 27158486349294 | 271010145 |
| 12 | 25 | 432 | 24491570206131 | 244342655 |

The first data set orders b by increasing integer mask, with bit k giving
b_k, then orders a increasingly. The second orders b lexicographically,
then a increasingly. Both order row pairs k<l lexicographically. In each
set, the equation order is the six single-column families in §2, followed
by one block per retained type. Each conditional block uses the ten
feature families in §3 in their displayed order. The conditional equations
are `pair-feature sum − required sum · N_i = 0`. The two checkers use
different exact inverse and graph-isomorphism implementations and their
respective vector orders. Both verify all 102 cases independently.

As an illustrative case, the empty graph gives column weights 10,11,12,
with counts 6,21,5. For two columns with respective weights (10,10),
(10,11), (10,12), (11,11), (11,12), (12,12), the permitted overlaps are
{2,3}, {3,4}, {5}, {3,4,5}, {4,5}, {4}. Fix a weight-12 column.
Among the other columns there are six of weight 10, twenty-one of weight
11, and four of weight 12. The overlap sum 12·12=144 forces fourteen
of the weight-11 columns to have overlap 5 and seven to have overlap 4.
Their pair-overlap sum is then

    6 binom(5,2)+14 binom(5,2)+7 binom(4,2)+4 binom(4,2)=266,

contradicting the required 4 binom(12,2)=264.

All 102 defect graphs are excluded, so a 27-word code cannot exist.
Together with §1, this proves A(32,16,13)<=26. It does not assert equality.
