# A(21,8,9) <= 287

The certificate applies to Polak's complete four-point bound A₄ [1].
For the set W of all weight-nine words, assign a moment x(S) to each
subset S of W of size at most four, with x(empty set)=1, x(S)=0 when
S contains a forbidden pair, and x(S)>=0. For an anchor D define

    C4(D) = {S : D subset S, |D| + 2|S\D| <= 4},
    M4,D(x)[S,T] = x(S union T),  S,T in C4(D).

Require these matrices to be positive semidefinite and maximize the sum
of singleton moments. A true code gives feasible indicator moments, so
the optimum bounds its size. Averaging over coordinate permutations
gives the invariant version. With V = binom(21,9) = 293930, the supplied
model uses z(S)=V·average(1[S subset C]); its singleton variable is |C|.
Variable zero is the affine constant 1, while the empty-set moment is V.

The complete A₄ includes the empty-anchor four-point matrix. The weaker
B₄ substitutes three-point matrices for the smaller anchors as defined
in [1]. Table II in that paper gives 294 for (21,8,9), without an asterisk:
the table footnote assigns that value to B₄. The present integer bound
287 is a certified bound from the complete A₄. No assertion about the
exact optimum of that semidefinite program is needed.

## Model and exact dual format

`data/A21_8_9_full.json` indexes the full integer matrices; the compressed
JSON-lines files it names contain one block per line. A block has a label,
its size, and entries `[variable,row,column,integer coefficient]` for
row <= column. It represents

    F_b(z) = F_b,0 + sum_i z_i F_b,i >= 0.

The full model has 10665 nonconstant variables, 707 structural blocks,
10665 nonnegativity blocks, and 558841903 stored coefficients. Its largest
structural matrix has order 165. `data/A21_8_9_principal.json` describes
11368 retained blocks, with largest order 87 and 156029979 coefficients.
The fields `source_block` and `kept_columns` identify each principal
submatrix. The checker compares every retained coefficient with its
position in the full model; it does not infer equality from a hash alone.
The 10665 scalar nonnegativity blocks are also checked explicitly.

The certificate `attachments/A21_8_9_certificate.json.gz` supplies integer
matrices R_b, nonnegative integer row exponents p_b,i, and a positive
integer denominator D. The rational dual matrix is

    Y_b[i,j] = sum_k R_b[i,k] R_b[j,k] / (D² 2^(p_b,i+p_b,j)).

It is positive semidefinite because it is a rational Gram matrix. With
the trace product counting off-diagonal positions twice, define

    r_0 = sum_b <Y_b,F_b,0>,
    r_i = 1[i=1] + sum_b <Y_b,F_b,i>.

All 10665 nonconstant residuals are nonpositive. Thus the exact identity

    r_0 - z_1 = sum_b <Y_b,F_b(z)> + sum_i (-r_i)z_i >= 0

proves

    A(21,8,9) <= 57529569329575917506024543440753
                / 200000000000000000000000000000
              = 287.647846647879587530122717203765 < 288.

Taking the floor gives 287. The residual compensation is exactly zero.
This is an integer and rational verification; no numerical tolerance or
solver is involved. Exact residual treatment for coding bounds is also
discussed in Brouwer–Polak [2, Appendix, equations (13)–(17)].

Use `python verify.py 21 8 9` for the detailed check, or
`python verify.py --all` for the complete update. Place every compressed
attachment listed in the two indexes in `attachments/`. The matrices
encode Polak's symmetry reduction; the dual check certifies the supplied
integer model, while the moment definition and [1] provide its code
feasibility interpretation. It does not reconstruct that representation
theory from first principles.
